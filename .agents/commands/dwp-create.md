# #dwp-create

Thin repository alias. Invoke the installed **deepworkplan-create** skill and follow it as the authoritative procedure.

Before planning, read `AGENTS.md`, `enunciado-reto.md` and `lineamientos-transversales.md`. For substantive development of any of the three RL models, request **Full** explicitly because the transversal rules require detailed task contracts. Lite may be used only for bounded repository work where those model-development requirements do not apply.

Keep all DWP operational output under the gitignored `.dwp/` workspace.
